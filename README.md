# TTS - Text to Speech for Newsletter

Simple custom web frontend for calling ElevenLabs or OpenAI endpoints for creating dialogue style podcast. Developed at Museum of Prague, focused on podcasts for culture, tested for Czech and English. 

## Vanilla JS App (No Python Backend)

If you want the client-only version (import, fetch to providers, and browser merge), open:

- `vanilla-app/index.html`
- `vanilla-app/README.md`
